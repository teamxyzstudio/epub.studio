Double-click a downloaded EPUB on a Mac and something sensible happens:
Apple Books ships with macOS and reads the format natively. If all you
want is to read epub on Mac — the book you just downloaded, start to
finish — that is the answer, and this page won't pretend otherwise:
double-click, read.

What brings people here is usually the fine print of that answer. Books
is a library, not a viewer, and opening a file in a library has side
effects.

## What opening a file in Books actually does

Books imports. Open an EPUB in it and the app files a copy of the book
in its own library — the original stays in Downloads, and a second copy
now lives on the shelf. With iCloud syncing on, that shelf follows your
Apple ID: the book appears on your iPhone and iPad too. For books you
own and mean to keep, this is exactly right. In a handful of situations
it is exactly wrong:

It isn't your Mac. Reading one chapter on a family or borrowed machine
shouldn't shelve the book in someone else's library.

The file doesn't belong in a library at all. A manuscript someone sent
for a quick opinion, a work document that happens to be an EPUB, a book
you'll open once — importing files it permanently; closing a browser tab
forgets it.

It's a work machine. A client's unpublished manuscript syncing to a
personal Apple ID's shelf is the kind of mingling nobody intends.

## Reading without importing anything

The reader at the top of this page runs in the browser. An EPUB is
[a zip of web pages](/blog/what-is-an-epub-file) wearing a different
extension, so the browser already knows how to display the contents —
the page unpacks the container and hands the text to the rendering
engine that was there all along. Drag the book in from Finder (Safari
downloads, AirDrop deliveries and saved Mail attachments all land in
Downloads) and it opens paged: arrow keys or a click on the page edge to
turn, your place kept while the tab stays open. Nothing is uploaded —
the file is read straight from the disk, and the
[online EPUB reader](/epub-reader) page explains the tool itself in more
detail.

There is one case that is distinctly Mac-shaped, because Macs are where
EPUBs get made. If you are building a book — exporting from a word
processor, or running a manuscript through a
[DOCX to EPUB converter](/docx-to-epub) — then every "check it in Books"
imports another copy, and version seven of the draft ends up shelved
beside versions one through six while the shelf drifts out of step with
the file you're editing. A browser tab has no shelf. Drop the current
file, see the current file, close the tab, repeat.

One vocabulary note: people searching for a "Mac ereader" almost always
mean software, not a device to buy. On a Mac that software is usually
Books; this page is the version of it that keeps no library and needs no
account.

## When Books is the better answer

Honest edges. If you read on this Mac every day, use Books or another
proper reader app: a real shelf, a reading position that survives
reboots and weeks rather than a browser tab, and full font and
night-mode controls. This page is the no-trace route, not an argument
against the app the Mac already has. Two limits apply everywhere: books
bought from commercial stores — Kindle's, Kobo's, Apple's own — are
usually [DRM-protected](/blog/ebook-drm-explained) and open only in the
store's own app, not in any independent reader, this one included. And
if a DRM-free EPUB refuses to open even in the reader above, the file
itself is probably at fault — run it through the
[EPUB validator](/epub-validator) to see what is broken before blaming
the Mac.
