A course reader is a publishing job with a weekly deadline. Handouts live in
Word, the readings for week three ought to be one file instead of four, and
the class will open all of it on whatever devices they already own — phones
included. The tools on this page cover that job end to end, in the browser,
free, with no account. The drop zone above is the first step and it is the
actual converter, not a picture of one.

Start with why the format is worth the bother. A PDF is a frozen page — the
layout is the content, which is exactly right for a worksheet with blanks to
fill in, and exactly wrong for twelve pages of reading on a phone. EPUB is
reflowable: the text re-wraps to the screen it lands on, and the reader — the
person and the software — decides the text size. A student who needs large
print gets it from the same file as everyone else. That is also why an EPUB
has no fixed page numbers to cite; "page 47" belongs to paper and PDF, so
point students at chapter and section names instead.

The conversion itself has one rule that repays learning: structure comes from
Word's real styles, not from what the text looks like. A reading titled in
bold 16-point body text converts as an ordinary paragraph; the same title set
as Heading 1 becomes a chapter break and a table-of-contents entry. Check the
navigation pane in Word before converting — if the titles show up there, the
EPUB will be organised.

Then assembly. [Merge](/merge-epub) takes the converted readings in the order
you add them and produces one file with one table of contents, each reading
listed by name. One file beats a folder of attachments for the same reason a
bound reader beats loose photocopies: nothing goes missing and the order is
part of the object. The reverse operation is just as useful —
[Split](/split-epub) pulls a single chapter out of a longer book, which is how
you turn a 500-page public-domain novel into this week's assigned excerpt
without distributing the whole thing.

Size is the practical constraint, because course systems and inboxes cap
uploads. Text is never the problem — a semester of prose is smaller than one
photograph. Scanned pages and pasted images are the weight, and the
[Compressor](/epub-compressor) re-encodes exactly those, leaving every word
untouched, so a packet built from scans comes back at a fraction of the size.

On the reading side, assign nothing that needs installing. The
[browser reader](/epub-reader) opens an EPUB on any machine with a browser —
including managed school laptops and library computers where students cannot
install software. Built-in phone book apps handle EPUB too. Either way, the
file you distribute is the only thing students need.

Two honest limits. First, copyright: convert what you have the right to
share — your own materials, public-domain texts, openly licensed work. Files
from textbook platforms and library apps carry DRM; they will not open here,
and this site never removes DRM in either direction. Second, distribution:
there is no integration with any course system. These tools make the file;
handing it out happens wherever you already post course materials.

None of it costs anything and none of it requires an account. The shelf below
is the whole workflow, in order.
